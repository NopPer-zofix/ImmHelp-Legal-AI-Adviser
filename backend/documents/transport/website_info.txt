These are external web pages on Cyprus driving and vehicle rules. They are LINKS, not content:
the page text has not been read into this knowledge base. Point the user to the relevant link
when their question matches one of the topics below, and do not state what a page says as if it
had been read. Anything presented as fact must come from the official forms and guides in this
folder or be flagged to the user as something to confirm.

HOW TO ADD AN ENTRY: one block per page - a "Title : URL" line, then a "Covers:" line listing the
terms someone would actually search for. The Covers line is what makes the entry findable, so
write the words a user would use, not the words on the page.
